# Proposal

## Why

女儿目前初中，需要提前建立上海高考英语词汇基础，但市面上多数背单词 App 面向通用考纲，缺少上海高考视角，也无法验证「她会不会每天坚持用」。先用最小成本跑通一个每天可用的词汇复习闭环，验证使用习惯后，再扩展到听力与阅读。

## What Changes

- 新增一个可在 iPhone 上以 PWA 方式「添加到主屏幕」使用的词汇学习应用，零成本、无需 Apple 开发者账号、不依赖后端。
- 内置首批 300 个上海高考高频核心词的词库（JSON），以考纲词表为主干，预留学段/教材/考纲级别标签字段。
- 基于 FSRS 的认读卡片复习：今日队列、翻面看释义、自评反馈、下次复习时间调度。
- 单词列表与搜索、系统 TTS 发音、应用内复习提醒、学习统计。
- 学习进度可导出为 JSON，保证将来迁移到原生 App 时不丢数据。
- **明确不做（v1 out of scope）**：听力模块、阅读模块、账号与云同步、Web Push 推送、真人音频、App Store 上架。

## Capabilities

### New Capabilities
- `vocab-srs`: 上海高考词汇的认读卡片学习与 FSRS 间隔复习行为，覆盖词库加载、今日复习队列、卡片自评与调度、进度统计、进度导出与导入。

### Modified Capabilities
- 无。

## Impact

- 新增前端工程：Vite + React + Dexie（IndexedDB）+ vite-plugin-pwa，静态托管于 GitHub Pages。
- 新增词库数据文件（JSON）及本地数据模型（词条、复习状态、学习记录）。
- 无后端服务、无第三方 API；发音使用浏览器/系统的 SpeechSynthesis。
- 内容风险：词库需从公开考纲整理，不打包受版权保护的教材配套音频或高考真题；发音先用系统 TTS 兜底。
